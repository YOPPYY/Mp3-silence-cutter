# MP3 範囲カットツール

MP3の始点と終点を指定して、その外側(始点より前・終点より後)をカットするブラウザツールです。
インストール不要で、`mp3-silence-cutter.html` をブラウザで開くだけで使えます。ファイルはブラウザ内で処理され、外部に送信されません。

## 使い方

1. **ファイルを読み込む**
   MP3をドロップするか、枠をタップして選びます。読み込み中は進捗(%)と残り時間が表示されます。

2. **範囲を決める**(始点より前と、終点より後がカットされます)
   - 波形をタップして指定します。「波形タップ=始点 / 終点」のラジオで、どちらを動かすか切り替えます。
   - 始点・終点の欄に、`0:01:23.45`(時:分:秒)の形式で入力することもできます。`83.5` や `1:23.5` でも読み取れます。
   - 無音リストの「始点に」「終点に」ボタンで、無音の位置から指定することもできます。音の境目から、設定した秒数ぶん無音を残します。

3. **確認する**
   - 波形の水色の部分が、残る範囲です(範囲外はグレー)。始点は緑、終点は赤の線で示されます。
   - 「最初から」は全体を、「始点から」は選んだ範囲を再生します。「停止」で止まり、「選択解除」で全体に戻ります。

4. **書き出す**
   「選択範囲を書き出し」を押すと、進捗(%)と残り時間が表示されます。完了するとダウンロードボタンと試聴プレーヤーが出ます。
   出力ファイル名は `元のファイル名_trim.mp3`(WAVの場合は `.wav`)です。

## 設定

| 項目 | 内容 |
|---|---|
| 無音とみなす音量(dB) | この音量より小さい部分を無音として扱います。無音リストの検出条件です。 |
| 検出する無音の長さ(秒) | この長さ以上の無音だけをリストに出します。 |
| 書き出し時に残す無音の長さ(秒) | 無音リストから始点・終点を指定するとき、音の境目に残す無音の長さです。 |
| 出力形式 | 自動(入力と同じ音質)/ MP3 128・192・320kbps / WAV(劣化なし)。 |

- 出力形式の初期値は「自動」で、入力のビットレートを推定して合わせます。判定できない場合は192kbpsになります。
- すべての設定は、ブラウザに保存され、次回起動時に復元されます。シークレットモードなど、保存領域が使えない環境では保存されません。

## 注意

- MP3の書き出しは再エンコードになるため、わずかに音質が変わります。劣化を避けたい場合は、WAVを選んでください。
- サンプリングレートとチャンネル数は、入力のままです。
- MP3エンコーダ(lamejs)とWASMデコーダ(mpg123-decoder)は、CDNから読み込みます。オフラインでは、これらが使えない場合があります。エンコーダを読み込めないときは、WAVで出力されます。
- 読み込みに失敗する場合は、MP3以外の形式のファイルか、ファイルが壊れている可能性があります。
